# CI на GitHub Actions

Генерируется с `--GitHubCiCd`, по умолчанию выключено: у каждой команды свой CI, а эти workflow работают
только на GitHub. Флаг передаётся с `-M false`; workflow покрывают все сервисы в `All.sln`, поэтому
следующему сервису ничего больше не нужно.

## `.github/workflows/ci.yml`

Запускается на каждом пулл-реквесте, на push в `main` или `master` и вручную:

1. Падает, если проект сервиса отсутствует в `All.sln`. Сервис добавляется туда скриптом
   `src/services/manual-add-projects.sh`; если про это забыть, сервис выпадет из сборки и из тестов, и
   ничего не упадёт.
2. Собирает `All.sln` в Release.
3. Запускает юнит-тесты: всё, что не помечено `[Category(TestCategories.Integration)]`.
4. Запускает интеграционные тесты на реальных серверах, поднятых в джобе: PostgreSQL всегда, ClickHouse
   с `--ClickHouse`, SeaweedFS с `--Storage`. PostgreSQL держит данные на ramdisk с выключенной
   надёжностью записи; это безопасно только потому, что данные умирают вместе с джобом. См.
   [тестирование](../architecture/testing.md).
5. Сливает покрытие обоих прогонов в один отчёт: сводка на странице прогона, HTML-отчёт в артефакте.
   Миграции, конфигурация модели, композиция DI, настройка хоста и сидинг исключены.

Покрытие ветвлений валит прогон, если оно ниже переменной репозитория `COVERAGE_MIN_BRANCH`, в
процентах. Без переменной отчёт показывается и ничего по нему не падает: команда задаёт порог, когда
тесты появятся, и поднимает его без правки workflow.

## `.github/workflows/secret-scan.yml`

Прогоняет [gitleaks](https://github.com/gitleaks/gitleaks) по коммитам, которые приносит пулл-реквест или
push, с `tools/gitleaks/.gitleaks.toml`: набор правил gitleaks плюс пароли в строках подключения, URI с
учётными данными и ключи подписи в JSON-настройках. Значения с пометкой `test-do-not-use`, `placeholder`
или `changeme` и ссылки `${VARIABLE}` разрешены.

Сканируются только входящие коммиты, поэтому находка в старой истории не валит каждый следующий прогон.
Чтобы один раз просканировать всю историю, например при подключении workflow в существующем репозитории:

```bash
gitleaks detect --config tools/gitleaks/.gitleaks.toml --redact
```
