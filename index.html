DotNetSolutionKit AboutО шаблоне DocsДокументы SamplesПримеры GitHub

A dotnet new template for .NET 10 and PostgreSQL or SQL Server. It creates the structure of a solution and the projects of its microservices, already wired together. The rest comes with flags.

Шаблон dotnet new для .NET 10 и PostgreSQL или SQL Server. Создаёт структуру решения и проекты микросервисов, уже связанные между собой. Остальное включается флагами.

NuGetSawKing.DotNetSolutionKit

dotnet new DotNetSolutionKit -N MyCompany -P MyProduct -S Orders -M false

Start with the business logic

Начните сразу с бизнес-логики

Setting up a new microservice usually eats a week: layers, errors, auth, logging, tests, Docker, CI. Here it takes one command, and the first commit is already the product.

Настройка нового микросервиса обычно съедает неделю: слои, ошибки, авторизация, логи, тесты, Docker, CI. Здесь это одна команда, и первый коммит уже про продукт.

A new service in one command. dotnet new adds it to the solution with its layers, references, tests and deployment files in place.

Новый сервис одной командой. dotnet new добавляет его в решение сразу со слоями, ссылками, тестами и файлами деплоя.

The boring part is done. Errors in one format, validation, authorization, health checks, background jobs and one request ID that follows a call through every service and log.

Рутина уже сделана. Ошибки в одном формате, валидация, авторизация, проверки здоровья, фоновые задачи и один ID запроса, который проходит через все сервисы и логи.

Only what you need. A message bus, secrets from Infisical or Vault, object storage, ClickHouse, an audit journal, an API gateway - each is a flag, switched on when you need it.

Только то, что нужно. Шина сообщений, секреты из Infisical или Vault, объектное хранилище, ClickHouse, журнал аудита, API-шлюз - каждое включается флагом, когда понадобится.

Ready for production. Docker images, compose or Kubernetes, blue-green deployment and CI on GitHub Actions with tests on a real database.

Готово к продакшену. Docker-образы, compose или Kubernetes, blue-green деплой и CI на GitHub Actions с тестами на настоящей базе.

See it before you use it. DotNetSolutionKit.Samples holds generated solutions to read through: the full kit, a single service and a gateway with services, generated again from every release, and nightly, generated from master. Each runs its own CI.

Посмотрите до того, как взять. В DotNetSolutionKit.Samples лежат сгенерированные решения: полный комплект, один сервис и шлюз с сервисами, которые пересобираются из каждого релиза, и ветка nightly, собранная из master. В каждой работает свой CI.

Try it in a minute

Попробуйте за минуту

Install the template from nuget.org:

Установите шаблон с nuget.org:

dotnet new install SawKing.DotNetSolutionKit

The shared libraries, the solution and the first service:

Общие библиотеки, решение и первый сервис:

dotnet new DotNetSolutionKit -N MyCompany -P MyProduct -S Orders -M false

Every next service:

Каждый следующий сервис:

dotnet new DotNetSolutionKit -N MyCompany -P MyProduct -S Billing
